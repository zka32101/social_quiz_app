## 実装ステップ

### Phase 1: Data Layer
```dart
// lib/models/timeline_entry.dart 新規作成
// lib/services/timeline_service.dart 新規作成

class TimelineService {
  // クリアされたエントリ一覧取得
  Future<List<TimelineEntry>> getClearedEntries() async {
    final json = await _prefs.getString('app_timeline_entries');
    return json != null 
        ? (jsonDecode(json) as List)
            .map((e) => TimelineEntry.fromJson(e))
            .toList()
        : [];
  }
  
  // エントリ追加
  Future<void> addTimelineEntry(TimelineEntry entry) async {
    final entries = await getClearedEntries();
    entries.add(entry);
    await _prefs.setString(
      'app_timeline_entries',
      jsonEncode(entries),
    );
  }
}
```

### Phase 3: Riverpod Provider
```dart
final timelineServiceProvider = Provider((_) => TimelineService());

final timelineEntriesProvider = FutureProvider<List<TimelineEntry>>((ref) async {
  final service = ref.watch(timelineServiceProvider);
  return await service.getClearedEntries();

final timelineProgressProvider = FutureProvider<int>((ref) async {
  final entries = ref.watch(timelineEntriesProvider);
  return entries.whenData((list) => list.length);
```

```dart
void addScore(int points, Quiz quiz) {
  state += points;

    final entry = TimelineEntry(
      year: quiz.year!,
      description: quiz.question,

      clearedAt: DateTime.now(),

    ref.read(timelineServiceProvider).addTimelineEntry(entry);

  }
```

**優先度**: 6位  
**推定工期**: 3日  
**難易度**: 低（既存UI流用）

## 概要
「もし○○だったら？」の if 問題で歴史的思考力を鍛える。中学受験の記述問題対策に直結。

## データモデル

### HistoricalThinkingQuiz（拡張）
```dart
@freezed
class HistoricalThinkingQuiz with _$HistoricalThinkingQuiz {
  const factory HistoricalThinkingQuiz({
    required int id,
    required String ifQuestion,   // "もし鎖国をしていなかったら..."
    required String historicalContext, // 背景
    required List<String> options,
    required int correctIndex,
    required List<String> explanations, // 各選択肢の背景知識
    required String reasoning,    // なぜこれが正解か？（因果関係）
  }) = _HistoricalThinkingQuiz;
}
```

## クイズの構造例
```
Q: 「もし平氏が壇ノ浦の戦いで勝っていたら、
    日本の政治体制はどうなっていたと考えられるか？」

A1: 平氏による武家政権が確立された（✓ 正解）
    理由: 平氏の軍事力が源氏を上回っていたため、
          平氏が幕府を開く可能性が高い

A2: 貴族政治が続いた
    理由: 違う。武家の力が強まっていた

A3: 大宗教団体が政権を担う
    理由: 不可能。当時の軍事力体制では実現不可

A4: 中国からの征服を受けた
    理由: 当時の大陸情勢では考えにくい
```
